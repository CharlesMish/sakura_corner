# Scene review captures

**Looking for the current scene?** Start with the
[four current previews](../docs/images/README.md) or the [project README](../README.md).

This directory retains development comparisons and verification evidence.
The many older images are not alternative versions of the current preview.

| Set | What it contains |
| --- | --- |
| [nocturne-weather](nocturne-weather/) | Latest final frames, baseline comparisons, controls checks, and recordings. Files starting `final-` show the current scene. |
| [nocturne-everyday](nocturne-everyday/) | Earlier shop lettering, notice, crate, roof, and window-plant review. |
| [nocturne-temporal](nocturne-temporal/) | Earlier canonical-motion recording and telemetry. |
| [nocturne](nocturne/) | Earlier material, lighting, and street-detail comparisons. |

Loose `signoff-*` and `rain-contact-*` files belong to older checkpoints.
`baseline-*`, `compare-*`, `gray-*`, `thumb-*`, and detail crops are review
tools, not the main presentation images.

See the [weather report](../docs/WEATHER_MODES.md) for measurements and the
limits of the recorded visual review. Previous captures remain unchanged.
